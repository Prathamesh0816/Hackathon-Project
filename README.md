1. Clone repo
git clone <repo-url>

Then navigate to 
cd trupulse-api

2. Create a new virtual environment
py -m venv venv


4. Activate it

PowerShell:

.\venv\Scripts\Activate.ps1

You'll see:

(venv)
4. Install everything from requirements.txt
pip install -r requirements.txt

or

python -m pip install -r requirements.txt
